# 01. 제품 요구사항

## 1. 목표

사용자가 선택한 회사의 주가 변화를 숫자나 차트만이 아니라 모니터 위 캐릭터의 감정과 행동으로 직관적으로 확인할 수 있는 Windows 데스크톱 펫 앱을 만든다.

## 2. 대상 사용자

- 업무 중 특정 회사의 주가 흐름을 가볍게 확인하고 싶은 사용자
- 복잡한 HTS 대신 간단한 상태 표현을 원하는 사용자
- 데스크톱 캐릭터를 화면에 띄워두고 싶은 사용자

## 3. MVP 범위

### 포함

- Windows 10/11
- 한 개의 국내 주식 종목
- 현재가, 전일 종가 대비 등락률
- 주가 상태별 캐릭터 애니메이션
- 투명하고 테두리 없는 펫 창
- 항상 위 표시
- 드래그 위치 이동
- 클릭 통과 모드
- 시스템 트레이
- 설정 창
- 종목 및 반응 임계값 설정
- 설정 저장과 복원
- Mock 주가 테스트 모드
- 네트워크 및 데이터 오류 처리
- Windows 설치 파일

### 제외

- 실제 매수·매도
- 계좌 잔고 조회
- 여러 종목 포트폴리오
- 주가 예측과 투자 추천
- 뉴스 감성 분석
- 모바일 앱
- 사용자 계정 서버
- 펫 육성 및 아이템

## 4. 기능 요구사항

### FR-001 실행

- 저장된 설정을 불러온다.
- 마지막 위치에 펫 창을 표시한다.
- 대상 종목 미설정 시 설정 화면을 연다.
- 펫 숨기기와 앱 완전 종료를 구분한다.

### FR-002 펫 창

- 투명 배경
- 창 테두리 없음
- 항상 위 선택 가능
- 작업 표시줄 일반 창에서 제외
- 드래그 이동
- 마지막 위치 저장
- 다중 모니터 안전 복구

### FR-003 종목 설정

- 종목명 또는 종목코드 검색
- 한 종목 선택
- 데이터 수신 시험
- 종목 변경 시 직전 종목 가격 이력 초기화

### FR-004 주가 수집

초기 기본 갱신 주기는 60초다. 선택 가능한 값은 30, 60, 180, 300초다.

내부 공통 모델:

```ts
export type StockSnapshot = {
  market: "KR";
  symbol: string;
  companyName: string;
  currentPrice: number;
  previousClose: number;
  changePrice: number;
  changeRate: number;
  marketStatus: "PRE_OPEN" | "OPEN" | "CLOSED" | "HOLIDAY" | "UNKNOWN";
  receivedAt: string;
};
```

### FR-005 기본 상태

기본 임계값:

| 상태 | 기준 |
|---|---:|
| STRONG_UP | +3.0% 이상 |
| UP | +0.5% 이상, +3.0% 미만 |
| FLAT | -0.5% 초과, +0.5% 미만 |
| DOWN | -3.0% 초과, -0.5% 이하 |
| STRONG_DOWN | -3.0% 이하 |

### FR-006 순간 이벤트

- 직전 가격보다 상승: TICK_UP
- 직전 가격보다 하락: TICK_DOWN
- 설정 시간 안에 +1% 이상: SURGE
- 설정 시간 안에 -1% 이하: DROP
- 순간 이벤트 종료 후 현재 기본 상태로 복귀

### FR-007 설정

- 대상 종목
- 강한 하락, 하락, 상승, 강한 상승 기준
- 급변 기준
- 이벤트 지속 시간
- 애니메이션 속도 배율
- 펫 크기
- 항상 위
- 클릭 통과
- 투명도
- 갱신 주기
- Windows 자동 실행

임계값은 아래 순서여야 한다.

```text
strongDown < down < up < strongUp
```

### FR-008 데이터 오류

- 실패 시 마지막 정상 데이터 유지
- 최신 데이터가 아님을 표시
- 자동 재시도
- 연속 5회 실패 시 DATA_ERROR
- 앱 강제 종료 금지

### FR-009 테스트 모드

Mock 상태를 버튼으로 발생시킬 수 있어야 한다.

- +5.0%
- +1.0%
- 0.0%
- -1.0%
- -5.0%
- 장 마감
- 데이터 오류

## 5. 투자 관련 제한

앱의 캐릭터 반응은 투자 추천이나 가격 예측을 의미하지 않는다. 매수·매도 지시 문구를 출력하지 않는다.
