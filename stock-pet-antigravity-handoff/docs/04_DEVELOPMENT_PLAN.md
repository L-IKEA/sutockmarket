# 04. 단계별 개발 계획

## Phase 0. 안전한 프로젝트 초기화

- Git 저장소 초기화
- 문서와 그래픽 첫 커밋
- Tauri/Node/Rust 개발 환경 확인
- 빌드 명령 문서화
- 실제 API 키 없음 확인

완료 조건:

- `git status`가 정상
- 프로젝트 루트 밖 파일을 수정하지 않음
- 초기 커밋 생성

## Phase 1. 프로젝트 골격과 애니메이션 플레이어

구현:

- Tauri 2 + React + TypeScript + Vite
- 투명한 기본 펫 창
- manifest 타입과 로더
- PNG 프레임 플레이어
- Animation Preview
- Mock 상태 버튼
- 누락 프레임 fallback
- 단위 테스트

이번 단계에서는 구현하지 않음:

- 실제 주가 API
- Stronghold
- 자동 시작
- 전체 설정 UI
- 설치 파일

완료 조건:

- 준비된 모든 애니메이션 선택 재생
- 프레임 추가·제거 후 플레이어 코드 수정 불필요
- Mock 상태 전환 정상
- 프레임 0/1/N개 테스트
- `npm test`, `npm run build`, `cargo test` 성공
- 실행 화면 검증 자료 제공

## Phase 2. 데스크톱 창과 트레이

- 항상 위
- 드래그 이동
- 클릭 통과
- 트레이 메뉴
- 숨기기/표시
- 위치 저장
- 다중 모니터 복구

## Phase 3. 설정 시스템

- 종목
- 반응 임계값
- 펫 크기 및 속도
- 창 설정
- 저장/적용/취소
- schemaVersion과 마이그레이션
- 잘못된 값 검증

## Phase 4. 상태 머신과 Mock 데이터

- 기본 상태
- 순간 이벤트
- 우선순위
- 이벤트 타이머
- 장 마감
- 오류 상태
- 경계값 테스트

## Phase 5. 실제 주가 API

- Provider 구현
- 인증
- REST 조회
- 응답 정규화
- 갱신 타이머
- 재시도
- 마지막 정상 데이터
- 비밀정보 저장

## Phase 6. 패키징

- Windows 설치 파일
- 아이콘
- 자동 실행
- 버전
- 설정 보존
- 사용자 안내
